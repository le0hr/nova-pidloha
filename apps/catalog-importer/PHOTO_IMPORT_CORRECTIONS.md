# Виправлення таблиці з фото

Оригінал: `prices_with_aliano_photos.xlsx`.
Виправлена копія для імпорту: `prices_with_aliano_photos_import.xlsx`.
Відтворення виправлень: `.venv/bin/python scripts/correct_photo_workbook.py`.

- На аркуші «Фурнітура» заголовок фільтрів P2 змінено з «ID варіації» на «ID товару». Це усуває 8687 помилок посилань; самі ID і значення фільтрів збережені.
- Для 29 моделей дверей підклас містив різні конструкції або напрямки відкривання. Залишено спільний підклас товару; повне початкове значення збережено в новій колонці J «Конструкція» для всіх 533 варіацій цих моделей. Це усуває 338 конфліктів ідентичності товару й неоднозначність варіацій.
- ID `2001` був одночасно в підлоги та фурнітури. У наявній базі CMS він належить товару фурнітури `Kofrad`; його збережено. Підлозі «Кварцвініл 2001» призначено `pidloha-2001`. У цій таблиці підлога не має додаткових посилань на старий ID.
- Назву аркуша `фурнiтура` нормалізовано до `Фурнітура`, як у попередньому файлі імпорту.
- Усі 33 файли зображень збережені побайтово. Координати прив’язки фото пересунуті разом із колонкою «Фото» після додавання колонки J.

Перевірка виправленої копії: 2740 товарів, 5870 варіацій, 0 помилок.
Одне попередження стосується порожніх рядків основної таблиці поруч із довшою секцією додатків; записи не видаляються.
